Jak zainstalować Gemini Nano (Chrome Beta 149)

Wymagania

  • Chrome Beta 149 lub nowszy (Linux 64-bit)
  • Około 4 GB wolnego miejsca na dysku
  • Połączenie z internetem (tylko podczas pierwszego pobierania)
Chrome Stable 148 nie obsługuje już Gemini Nano przez tę aplikację. Wymagany jest Chrome Beta 149+.

1 Zainstaluj Chrome Beta 149

  1. Pobierz Chrome Beta ze strony:
    https://www.google.com/chrome/beta/
  2. Zainstaluj – Chrome Beta i Chrome Stable mogą działać równocześnie
  3. Uruchamiaj aplikację wyłącznie w Chrome Beta

2 Włącz Prompt API

  1. W Chrome Beta otwórz nową kartę i wejdź na:
    chrome://flags/#prompt-api-for-gemini-nano
  2. Zmień wartość na Enabled

3 Włącz pobieranie modelu

  1. Wejdź na:
    chrome://flags/#optimization-guide-on-device-model
  2. Zmień wartość na Enabled BypassPerfRequirement
Wybierz BypassPerfRequirement, nie zwykłe „Enabled” – omija sprawdzanie wymagań sprzętowych, niezbędne na Linuksie.
  1. Kliknij Uruchom ponownie
  2. Dla pewności pełnego zamknięcia uruchom w terminalu:
    killall -9 google-chrome-beta
    …a następnie otwórz Chrome Beta ponownie

4 Pobierz model przez DevTools

Model nie pobiera się automatycznie – musisz go wyzwolić ręcznie przez konsolę DevTools.

  1. Na dowolnej stronie otwórz DevTools: F12 → zakładka Console
  2. Sprawdź dostępność modelu:
    await LanguageModel.availability()
    Oczekiwana odpowiedź: 'downloadable'
  3. Uruchom pobieranie (~3–4 GB):
    const session = await LanguageModel.create({
  monitor(m) {
m.addEventListener('downloadprogress', e => {
  console.log(e.loaded);
});
  }
});
  4. W konsoli będą pojawiać się liczby – to bajty już pobranych danych. Poczekaj, aż przestaną rosnąć (kilka–kilkadziesiąt minut)
Nie zamykaj DevTools ani karty podczas pobierania – przerwanie wymaga zaczęcia od nowa.

5 Przetestuj model

Po zakończeniu pobierania wpisz w konsoli:

const s = await LanguageModel.create()
await s.prompt("Napisz jedno zdanie po polsku")

Jeśli model odpowie po polsku – wszystko działa.

6 Odśwież aplikację

Odśwież tę stronę w Chrome Beta. Wskaźnik ✦ zmieni kolor na zielony z napisem AI – Gemini Nano jest aktywny i działa całkowicie offline.

Rozwiązywanie problemów

LanguageModel.availability() zwraca 'unavailable'

Sprawdź czy używasz Chrome Beta 149+ i czy obie flagi z kroków 2–3 są ustawione. Po zmianie flag zawsze wymagany jest pełny restart.

Pobieranie się zatrzymało / brak postępu w konsoli

Zamknij Chrome Beta, uruchom w terminalu:
killall -9 google-chrome-beta
Otwórz ponownie i powtórz krok 4 od początku.

Model pobrany, ale ✦ nadal pokazuje ⚠

Wykonaj pełny restart Chrome Beta:

killall -9 google-chrome-beta

Otwórz Chrome Beta ponownie i odśwież tę stronę.

Używasz osobnego profilu Chrome

Flagi chrome://flags są ustawiane osobno dla każdego profilu. Upewnij się, że flagi z kroków 2–3 są włączone w tym samym profilu, w którym używasz tej aplikacji.
